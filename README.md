# eventsphere
EventSphere ek complete Event Management Platform hai jahan users events discover, book aur manage kar sakte hain. Admin ke liye full control panel bhi hai.

## ✨ Features
- 🔐 Login / Signup System
- 🎟️ Events Browse & Search
- 📅 Event Create & Manage
- ✅ Event Booking System
- 🛠️ Admin Dashboard - Events, Users & Bookings Manage Karo
- 📱 Fully Responsive - Mobile & Laptop Dono Pe Perfect
- 🎨 Modern & Clean UI

## 🛠️ Tech Stack
- **Frontend:** React.js, HTML, CSS, JavaScript
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
